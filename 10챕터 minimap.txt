[SerializeField] private new Camera camera; <- 카메라
[SerializeField] private LayerMask floorLayers; <- 레이어
[SerializeField] private float height = 1; <- 높이
private LineRenderer lineRenderer; <- 라인 렌더러
private Ray[] rays = new Ray[4]; <- 선

private void Awake()
        {
            lineRenderer = GetComponent<LineRenderer>();
            lineRenderer.positionCount = 4;
        }
각 라인을 그리기 위한 점, 그리고 선은 4개가 필요하고 해당 선을 그리기 위해 라인 렌더러를 구해옴
private void Update()
        {
// 해당 위치를 기준으로.. 시작
            rays[0] = camera.ViewportPointToRay(new Vector3(0,0,0)); // bottom left
            rays[1] = camera.ViewportPointToRay(new Vector3(0,1,0)); // top left
            rays[2] = camera.ViewportPointToRay(new Vector3(1,1,0)); // top right
            rays[3] = camera.ViewportPointToRay(new Vector3(1,0,0)); // bottom right

            for(int i = 0; i < 4; i++)
            {
                if (Physics.Raycast(rays[i], out RaycastHit hit, float.MaxValue, floorLayers))
                {
                    lineRenderer.SetPosition(i, new Vector3(
                        hit.point.x,
                        height, // 높이는 외부에서 설정 가능
                        hit.point.z
                    ));
                }
            }
        }
매번 카메라가 업데이트 될 때마다 그 위치에 유지될 수 있게 지정해놓음, 각 Ray는 자기들의 점을 표시함
초기 위치에서 카메라가 움직일 때마다 바라보는 방향도 바뀌고 그러기 때문에 
미니맵에서 내 카메라가 지금 어딜 보고 있는지 RTS에서는 미니맵에 내가 바라보고 있는 시야의 네모랑 같은 것
그래서 이 위치가 자주 변동되기에 각 ray마다 x와 z의 위치를 변동시킴, 그게 위의 구조인데
제대로된 원리가 무엇이냐, 레이캐스트를 사용해서 카메라의 4개의 위치로 광선을 쏘고 그 광선이 접촉한 지면을 점으로 기록함
이렇게 4개가 기록된다면 lineRenderer는 자신의 4개의 위치를 그 접촉한 위치로 동기화시킴
그럼 선은 그려지고 RTS에서 흔히 볼 수 있는 미니맵의 내가 보는 시야 박스가 생기는 것
그 후 카메라 선 그리는 렌더러에 해당 스크립트를 적용, 물과 바닥만 적용시킴, 카메라는 메인 카메라
물리 효과가 적용되지 말아야할 곳에 체크 표시 해제(이 선도 포함이라 미니맵 전용으로 바꿈)

Get Mask와 NameToLayer의 차이는
레이캐스트, 충돌 검사용 마스크 / 게임 오브젝트의 레이어 설정
복수 레이어 지원 가능 / 불가능으로 나뉨
전자가 mask(비트) 후자가 레이어(인덱스)임
전자는 충돌 지정이나 레이캐스트로 맞을수 있냐없냐고
후자는 이걸 지정해서 레이어가 충돌 설정을 바꾸면 해당 레이어가 충돌이 될거냐 안될거냐 및
카메라로 그려질거냐 안 그려질거냐 등 구분이 가능함
그래서 원래 이 객체를 찾아내 화면 상에 보이고 시야 밖으로 나갔을 때 맵에는 보여야하는데
GetMask를 통해서 해버려서 바깥으로 나가면 사라졌음
NameToLayer를 통해 시야 밖으로 나가 안 보이게 되더라도 이제 발견되면 맵에 그대로 남아 그 위치를 표시해줌, 그대로 그림
